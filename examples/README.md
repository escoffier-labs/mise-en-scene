# Examples

A full run of Mise en Scene built from one short source file. Everything here is
generated by the studio from [`brigade-source.md`](brigade-source.md), which
describes an orchestration pipeline and its sidecars in the arrow grammar.

| File | What it is |
|---|---|
| [`brigade-source.md`](brigade-source.md) | The input source material |
| [`brigade-scene.html`](brigade-scene.html) | Interactive scene, offline. Architecture and sequence views, click to inspect elements |
| [`brigade-scene.png`](brigade-scene.png) | Architecture view, static raster |
| [`brigade-scene.svg`](brigade-scene.svg) | Architecture view, script-free vector |
| [`brigade-scene-sequence.png`](brigade-scene-sequence.png) | Sequence view, static raster |
| [`brigade-scene-sequence.svg`](brigade-scene-sequence.svg) | Sequence view, script-free vector |
| [`brigade-walkthrough.html`](brigade-walkthrough.html) | Animated walkthrough, offline. Plays a guided tour that zooms to each relationship |
| [`brigade-walkthrough.webm`](brigade-walkthrough.webm) | The same walkthrough, recorded as a video |

To regenerate: open the studio (`npm run dev`), paste `brigade-source.md`, and
use the export actions.
